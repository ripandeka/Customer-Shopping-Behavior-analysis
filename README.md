# Customer-Shopping-Behavior-analysis
End-to-end customer behavior analytics project using Python, PostgreSQL, and Power BI. Analyzes purchasing patterns, subscription behavior, category preferences, customer demographics, revenue trends, and shopping insights for a retail clothing brand.

## Overview

This project analyzes customer purchasing behavior for a retail clothing brand. The objective is to understand customer demographics, spending habits, subscription preferences, category performance, and revenue trends.

The analysis was performed using Python and PostgreSQL, followed by the development of an interactive Power BI dashboard.

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- PostgreSQL
- Power BI
- DAX

## Project Workflow

1. Data Exploration in Jupyter Notebook
2. Data Cleaning and Validation
3. Exploratory Data Analysis using PostgreSQL
4. Business Insight Generation
5. Dashboard Development in Power BI

## Key Insights

- The majority of customers are non-subscribers.
- Clothing generates the highest customer spending.
- Younger customers contribute the largest share of sales and revenue.
- Discount usage is highest in the Clothing category.
- Customer purchasing behavior varies across age groups and product categories.
